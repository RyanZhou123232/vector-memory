# Current HappyDB test questions

The old internship/contact questions have been retired with their dataset.
These questions were chosen before the new HappyDB smoke test:

1. Which everyday moments helped people feel that they belonged?
2. What low-key activities could give someone a breather after a draining day?

A no-match check:
Which entries describe repairing a nuclear reactor coolant valve?

All questions use the current multi-query retrieval and source-grounded synthesis
pipeline over HappyDB, not the former people-ranking code. Actual results and
timings are in .reports/happydb_smoke.json. Choosing final homework source examples
requires inspecting these real returned passages; no source ID was forced.
